## 확률 분포

### 이산 확률 분포

- 베르누이 분포
    - 결과가 0 아니면 1인 딱 1번의 시행
    - 평균: p
    - 분산: p(1-p)
- 이항 분포
    - 베르누이 시행을 n번 반복할 때의 성공 횟수
    - 평균: np
    - 분산: np(1-p)
    - $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$
        - n번 중 k번 성공하는 경우의 조합
        - k번 성공할 확률
        - n-k번 실패할 확률

```python
from scipy.stats import binom

n = 10
p = 0.5
print(binom.pmf(k=3, n=n, p=p))
mean, var = binom.stats(n=n, p=p)
binom.mean(n=n, p=p)
binom.var(n=n, p=p)
```

- 포아송 분포
    - 단위 시간/공간에서 사건이 몇 번 발생하는가
    - 평균 발생 횟수 λ
        - 1시간 동안 오는 전화 수, 1km 당 편의점 수
    - 이항 분포에서 n이 엄청 크고 p가 엄청 작으면 포아송 분포로 근사됨
    - 평균: λ / 분산: λ

### 연속 확률 분포

- 지수 분포
    - 첫번째 사건이 일어날 때 까지 걸리는 시간
    - 확률 밀도 함수 $f(x) = \lambda e^{-\lambda x}$
    - 확률은 면적의 크기로 계산함 $\int_0^{\infty} \lambda e^{-\lambda x}\,dx = 1$
    - 1초 당 평균 사건 발생 횟수 2일 때 0.1 초 안에 사건이 일어날 확률은?
        - $P(0 \leq X \leq 0.1) = \int_0^{0.1} 2e^{-2x}\,dx \approx 0.18$
    - 저런 확률이 식으로 정해져있다는게 신기하네…
        - 자연 현상을 관찰했더니 항상 저런 모양이더라 → 그걸 수식으로 정리한 것
        - 그래서 자연상수 (지수함수) e를 쓰나보당
    - 무기억성: 어떤 시점 부터 소요되는 시간은 과거 시간에 영향을 받지 않음
        - 지수함수의 특징이 미분해도 자기 자신이 나옴
        - 즉 변화율이 현재 값에 비례하다는 것
        - 지금까지 기다린 시간과 무관하게 매 순간 사건이 일어날 비율(위험률)이 항상 일정하다
- 정규 분포 (가우시안 분포)
    - 평균 μ, 표준편차 σ로 결정되는 좌우대칭 종 모양 분포
    - 표준정규분포 - 평균이 0, 표준편차가 1인 정규분포 (z 분포)
- t 분포
    - 모분산을 모를 때, 모집단에서 크기가 n인 표본을 추출
    - 자유도 (n-1) 이 커질수록 정규분포에 근사
    - 자유도가 작으면 꼬리가 두꺼워지고 크면 얇아짐
        - 자유도 적을수록 극단값이 나올 가능성이 더 반영된 것
    - 친구 키를 추정할 때
        - **정규분포**: 한국 성인 남성 평균/표준편차를 정확히 알고 있음
        - **t분포**: 주변 친구 5명만 재봐서 평균/표준편차를 추정함 → 더 불확실하니까 범위를 넓게 잡아야 함
- 카이제곱 분포
    - 표준정규분포를 따르는 변수 k개를 **제곱해서 합산**한 분포여기서도 자유도는 k
- 감마 분포
    - k번째 사건이 일어날 때까지의 시간
    - 지수 분포를 일반화한 것
    - 카이제곱 분포도 감마 분포의 특수 케이스
        - 3번째 고객이 도착할 때 까지 걸리는 시간

```
베르누이 ──n번 반복──▶ 이항분포
                        │ n→∞, p→0
                        ▼
이항분포 ─────────────▶ 포아송 분포
                        │ 사건 간 시간
                        ▼
포아송 ───────────────▶ 지수분포 ──k번──▶ 감마분포
                                              │
표준정규² 합산 ──────────────────────────▶ 카이제곱(감마 특수케이스)
                                              │
모분산 모를 때 ──────────────────────────▶ t분포
```

# 3. 기술 통계

## 기술통계량

### 위치 통계량

- 대표값, 자료의 중심점
- 평균
    - 산술 평균, 가중 평균, 기하 평균, 조화 평균
    
    ```python
    import numpy as np
    from scipy import stats
    
    data = [10, 20, 30, 40, 50]
    weights = [0.1, 0.2, 0.4, 0.2, 0.1]  # 가중 평균용
    
    # 1. 산술 평균 (Arithmetic Mean)
    arithmetic = np.mean(data)
    print(f"산술 평균: {arithmetic}")  # 30.0
    
    # 2. 가중 평균 (Weighted Mean)
    weighted = np.average(data, weights=weights)
    print(f"가중 평균: {weighted}")  # 30.0 (weights가 대칭이라 같음)
    
    # 3. 기하 평균 (Geometric Mean)
    geometric = stats.gmean(data)
    print(f"기하 평균: {geometric}")  # 약 26.05
    
    # 4. 조화 평균 (Harmonic Mean)
    harmonic = stats.hmean(data)
    print(f"조화 평균: {harmonic}")  # 약 21.83
    ```
    
    - **기하 평균**: 1년차 +50%, 2년차 -50% 수익률의 평균은?
        - 산술 평균 → 0% (틀림, 실제론 손해)
        - 기하 평균 → -13.4% (맞음, 실제 손실 반영)
    - **조화 평균**: 시속 60km로 가고 시속 40km로 돌아올 때 평균 속도는?
        - 산술 평균 → 50km/h (틀림)
        - 조화 평균 → 48km/h (맞음)
- 분위수
    - 사분위수
    - 1Q, 2Q(median), 3Q

### 변이 통계량

- 자료의 퍼짐/흩어짐 정도
- 분산
    - 각 데이터가 평균에서 얼마나 떨어져 있는지(편차)를 구한 뒤, 이를 **제곱하여 모두 더한 값의 평균**
    - Var(X) = E[(X - μ)²] = E[X²] - (E[X])²
- 표준편차
    - 분산의 제곱근
    - 값이 너무 커지는거 방지
- MSE (Mean Squared Error)
    - 오차 제곱의 평균
- RMSE (Root Mean Squared Error)
    - 얘도 값이 너무 커지는거 방지용
- 변동계수 (CV, coefficient of variation)
    - 표준편차를 평균으로 나눈 값
    - CV = μ / σ × 100
    - 단위가 다른 두 집단의 산포를 비교할 때 변동 계수를 사용!
        - 표준편차가 크면 평균도 크고 표준편차가 작으면 평균도 작음
        - 기존 데이터의 크기에 상관없이 정규화의 효과가 있음

### 모양 통계량

- 왜도: 분포의 치우친 정도
- 첨도: 분포의 뾰족한 정도(정규분포 기준)

## 확률 변수의 선형변환

- 표준편차: $𝑎(𝑎𝑋+𝑏) =|𝑎|𝜎(𝑋)$

# 4. 추론 통계

## 점 추정

- 표본으로부터 모수를 하나의 값으로 추정하는 것
    - 여기서 모수란 모집단의 특성 값 (ex. 모평균, 모분산 등)

## 구간 추정

- 점 추정은 신뢰도를 알 수 없음 —> 신뢰 구간을 사용
- 일정 확신으로 모수가 포함될 구간을 추정
- 신뢰구간
    - **x̄**: 표본평균
    - **Z_α/2**: 신뢰수준에 따른 Z값
    - **σ/√n**: 표준오차

한국 성인 남성 키, 표본 100명, 표본평균 173cm, 모표준편차 10cm라고 하면

**n이 충분히 클 때 표본평균의 분포는 N(μ, σ²/n)에 가까워진다**

## 상관 분석

두 변수가 선형적 관계가 있는 지, 얼마나 강한 지 측정

### 상관 계수

- 관계의 방향과 강도를 -1 ~ +1 사이의 값으로 표현
- +1 : 완벽한 양의 상관관계
- -1 : 완벽한 음의 상관 관계
- 0 : 상관 관계 없음
    
    ![Screen Shot 2026-05-31 at 10.41.34 PM.png](%ED%86%B5%EA%B3%84%20%EB%B6%84%EC%84%9D/Screen_Shot_2026-05-31_at_10.41.34_PM.png)
    

### 상관 분석의 종류

- 피어슨 상관계수
    - 가장 일반적으로 쓰는 상관 계수
    - 자료가 정규분포라고 가정
- 스피어만 상관계수
    - 자료가 정규 분포가 아니더라도 사용
    - 데이터를 순위로 변환해서 계산

```python
import pandas as pd
from scipy import stats

df = pd.DataFrame({
    '공부시간': [1, 2, 3, 4, 5],
    '시험점수': [50, 60, 70, 80, 90],
    '결석횟수': [5, 4, 3, 2, 1]
})

# 피어슨
r, p_value = stats.pearsonr(x, y)

# 스피어만
r, p_value = stats.spearmanr(x, y)

df.corr(method = "pearson")
#          공부시간  시험점수  결석횟수
# 공부시간    1.00    1.00   -1.00
# 시험점수    1.00    1.00   -1.00
# 결석횟수   -1.00   -1.00    1.00
```
