## 정규화 (Normalization)

특정 기준에 따라 자료의 단위를 변환하여 자료간 비교를 용이하게 할 수 있다

### 구간화 (Min-Max Scaling)

- 최대값, 최소값을 사용하여 원 데이터의 최소값을 0, 최대값을 1로 만듦
- 𝑁𝑄=𝑥−min(𝑥) / max(𝑥)−min(𝑥)
- 최소-최대 정규화라고도 부름
- 변환 하더라도 분포는 그대로!!

### 표준화 (Standardization)

- z-scoring을 통해 평균 0, 표준편차 1로 변환
- z = 𝑥−mean(𝑥) / std(𝑥)
- 변환 하더라도 분포는 그대로!!

### 지도학습 / 비지도학습

### 편향-분산 트레이드오프

- 편향(bias)
    - 편향이 크다 == 모델이 단순하다
    - 큰 편향은 과소적합 (under-fitting) 야기
- 분산(variance)
    - 분산이 크다 == 모델이 복잡하다 (꾸불꾸불)
    - 큰 분산은 과대적합 (over-fitting) 야기

## 머신러닝의 평가

### 회귀모델의 평가지표 (MSE, MAE, R²)

https://datadoctorblog.com/2023/08/12/Py-ML-Evaluation-Model-Regression/

수치형 변수의 평가는 관측값 (actual value) 과 예측값 (predicted value) 의 오차를 기반으로 한다
오차를 기반으로 하는 평가는 값이 작을 수록 좋다

- MSE : 오차의 제곱
- RMSE
- MAE : 오차의 절댓값 (Mean Absolute Error)
- MAPE : 백분율 오차 (Mean Absolute Percentage Error)

> MAPE는 종속변수에 0이 있으면 발산하기 때문에 사용에 주의
> 

```python
# 직접 계산해도 됨!

from sklearn.metrics import mean_absolute_error
mean_absolute_error(y_true, y_pred)

from sklearn.metrics import mean_squared_error
mean_squared_error(y_true, y_pred)
mean_squared_error(y_true, y_pred) ** 0.5

from sklearn.metrics import mean_absolute_percentage_error
mean_absolute_percentage_error(y_true, y_pred)

# MAPE는 시험의 라이브러리 버전에서는 지원 안한대.. 직접 계산ㅠㅠ
abs((df_y["true"] - df_y["pred"]) / df_y["true"]).mean()
```

- 결정계수 (R², coefficient of determination)
    - 회귀 모델이 주어진 자료에 얼마나 적합한 지 평가하는 지표
    - R² = 1 − (모델 썼을 때의 오차 / 그냥 평균으로 예측했을 때 오차)
    - 값의 범위는 기본적으로 0~1
    - 모델 성능이 좋지 않으면 음수가 나올 수 있음

| R² 값 | 의미 |
| --- | --- |
| 1.0 | 완벽한 예측 (모든 점이 예측선 위) |
| 0.8 | 총 변동의 80%를 모델이 설명 |
| 0.0 | 모델이 평균만큼만 설명 (쓸모없음) |
| 음수 | 평균보다도 못한 예측 |

### 분류모델의 평가지표 (Precision, Recall)

https://datadoctorblog.com/2023/08/04/Py-ML-Evaluation-Model-Classification/

Accuracy, Precision, Recall, F1 score 는 1 에 가까울수록 좋음 최소값은 0

- Accuracy
    - 올바르게 분류한 결과(True Positive, True Negative)의 비율
- Precision
    - Positive라고(True Positive, False Positive) 예측한 것 중에서 실제로 Positive인 것(True Positive)의 비율
    - 양성이라고 예측한 것 중 진짜 양성?
    - 스팸 메일 필터링
        - 스팸이라고 예측한 것 중에 진짜 스팸이 얼마나?
        - 스팸인데 아니라고 했어도 (False Negative) 큰 타격 X
- Recall
    - 실제 Positive(True Positive, False Negative) 중에서 Positive로(True Positive) 올바르게 분류한 비율
    - 실제 양성 중 얼마나 찾아냈나?
    - 암 진단
        - 실제 암 환자 중 얼마나 암환자라고 예측했는가
        - 암환자가 아닌데 암환자라고 예측 (False Positive) 큰 타격 X
- F1 Score
    - Precision와 Recall의 조화 평균으로 산출
    - F1 Score는 Precision과 Recall이 둘 다 좋아야 값이 높게 나옴

```python
from sklearn.metrics import accuracy_score
from sklearn.metrics import precision_score
from sklearn.metrics import recall_score
from sklearn.metrics import f1_score

accuracy_score(y_true, y_pred)
```

- ROC curve
    - 가로축을 False Positive Rate을 x축에, True Positive Rate 값을 y축에 표시한 그래프
    - 전체 면적 대비 곡선의 아래쪽 면적의 크기로 분류기의 성능을 평가
        - AUC(Area Under Curve)
        - false positive 가 조금 커져도 true positive가 금방 높아져야 좋은 모델

## 머신러닝 기초 이론

### 거리 및 유사도

자료 간 거리를 측정하여 유사도 판단 (row)

- 유클리드 거리
    - 두 점을 **직선으로 연결**한 거리
    - L2-norm에서 사용
- 맨하탄 거리
    - **가로/세로로만** 이동한 거리. 대각선 불가.
    - L1-norm에서 사용
    - 이상치가 많을 때 선택
- 코사인 유사도
    - 두 벡터간의 방향의 유사도
    - 방향이 완전히 동일하면 1
    - 90도 각을 이루면 0
    - 완전 반대 방향이면 -1

> 참고로 norm은 거리를 재는 함수를 의미함. normalize랑 아예 관계 없음!!
> 

```python
from sklearn.metrics.pairwise import euclidean_distances, manhattan_distances, cosine_similarity
import numpy as np

# 샘플 데이터 (2개의 벡터)
A = np.array([[1, 2, 3]])
B = np.array([[4, 6, 3]])

print(euclidean_distances(A, B))
# [[5.0]]  → √((4-1)²+(6-2)²+(3-3)²) = √(9+16+0) = 5
print(manhattan_distances(A, B))
# [[7.0]]  → |4-1|+|6-2|+|3-3| = 3+4+0 = 7
print(cosine_similarity(A, B))
# [[0.945...]]  → 1에 가까울수록 방향이 비슷함
```
