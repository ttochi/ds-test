## 정규화 (Normalization)

특정 기준에 따라 자료의 단위를 변환하여 자료간 비교를 용이하게 할 수 있다

### 구간화 (Min-Max Scaling)

- 최대값, 최소값을 사용하여 원 데이터의 최소값을 0, 최대값을 1로 만듦
- 𝑁𝑄=𝑥−min(𝑥) / max(𝑥)−min(𝑥)
- 최소-최대 정규화라고도 부름
- 변환 하더라도 분포는 그대로!!

### 표준화 (Standardization)

- z-scoring을 통해 평균 0, 표준편차 1로 변환
- z = 𝑥−mean(𝑥) / std(𝑥)
- 변환 하더라도 분포는 그대로!!

### 편향-분산 트레이드오프

- 편향(bias)
    - 편향이 크다 == 모델이 단순하다
    - 큰 편향은 과소적합 (under-fitting) 야기
- 분산(variance)
    - 분산이 크다 == 모델이 복잡하다 (꾸불꾸불)
    - 큰 분산은 과대적합 (over-fitting) 야기

## 머신러닝의 평가

### 회귀모델의 평가지표 (MSE, MAE, R²)

https://datadoctorblog.com/2023/08/12/Py-ML-Evaluation-Model-Regression/

수치형 변수의 평가는 관측값 (actual value) 과 예측값 (predicted value) 의 오차를 기반으로 한다
오차를 기반으로 하는 평가는 값이 작을 수록 좋다

- MSE : 오차의 제곱
- RMSE
- MAE : 오차의 절댓값 (Mean Absolute Error)
- MAPE : 백분율 오차 (Mean Absolute Percentage Error)

> MAPE는 종속변수에 0이 있으면 발산하기 때문에 사용에 주의
> 

```python
# 직접 계산해도 됨!

from sklearn.metrics import mean_absolute_error
mean_absolute_error(y_true, y_pred)

from sklearn.metrics import mean_squared_error
mean_squared_error(y_true, y_pred)
mean_squared_error(y_true, y_pred) ** 0.5

from sklearn.metrics import mean_absolute_percentage_error
mean_absolute_percentage_error(y_true, y_pred)

# MAPE는 시험의 라이브러리 버전에서는 지원 안한대.. 직접 계산ㅠㅠ
abs((df_y["true"] - df_y["pred"]) / df_y["true"]).mean()
```

- 결정계수 (R², coefficient of determination)
    - 회귀 모델이 주어진 자료에 얼마나 적합한 지 평가하는 지표
    - R² = 1 − (모델 썼을 때의 오차 / 그냥 평균으로 예측했을 때 오차)
    - 값의 범위는 기본적으로 0~1
    - 모델 성능이 좋지 않으면 음수가 나올 수 있음

| R² 값 | 의미 |
| --- | --- |
| 1.0 | 완벽한 예측 (모든 점이 예측선 위) |
| 0.8 | 총 변동의 80%를 모델이 설명 |
| 0.0 | 모델이 평균만큼만 설명 (쓸모없음) |
| 음수 | 평균보다도 못한 예측 |

### 분류모델의 평가지표 (Precision, Recall)

https://datadoctorblog.com/2023/08/04/Py-ML-Evaluation-Model-Classification/

Accuracy, Precision, Recall, F1 score 는 1 에 가까울수록 좋음 최소값은 0

- Accuracy
    - 올바르게 분류한 결과(True Positive, True Negative)의 비율
- Precision
    - Positive라고(True Positive, False Positive) 예측한 것 중에서 실제로 Positive인 것(True Positive)의 비율
    - 양성이라고 예측한 것 중 진짜 양성?
    - 스팸 메일 필터링
        - 스팸이라고 예측한 것 중에 진짜 스팸이 얼마나?
        - 스팸인데 아니라고 했어도 (False Negative) 큰 타격 X
- Recall
    - 실제 Positive(True Positive, False Negative) 중에서 Positive로(True Positive) 올바르게 분류한 비율
    - 실제 양성 중 얼마나 찾아냈나?
    - 암 진단
        - 실제 암 환자 중 얼마나 암환자라고 예측했는가
        - 암환자가 아닌데 암환자라고 예측 (False Positive) 큰 타격 X
- F1 Score
    - Precision와 Recall의 조화 평균으로 산출
    - F1 Score는 Precision과 Recall이 둘 다 좋아야 값이 높게 나옴

```python
from sklearn.metrics import accuracy_score
from sklearn.metrics import precision_score
from sklearn.metrics import recall_score
from sklearn.metrics import f1_score

accuracy_score(y_true, y_pred)
```

- ROC curve
    - 가로축을 False Positive Rate을 x축에, True Positive Rate 값을 y축에 표시한 그래프
    - 전체 면적 대비 곡선의 아래쪽 면적의 크기로 분류기의 성능을 평가
        - AUC(Area Under Curve)
        - false positive 가 조금 커져도 true positive가 금방 높아져야 좋은 모델

### 거리 및 유사도

자료 간 거리를 측정하여 유사도 판단 (row)

- 유클리드 거리
    - 두 점을 **직선으로 연결**한 거리
    - L2-norm에서 사용
- 맨하탄 거리
    - **가로/세로로만** 이동한 거리. 대각선 불가.
    - L1-norm에서 사용
    - 이상치가 많을 때 선택
- 코사인 유사도
    - 두 벡터간의 방향의 유사도
    - 방향이 완전히 동일하면 1
    - 90도 각을 이루면 0
    - 완전 반대 방향이면 -1

> 참고로 norm은 거리를 재는 함수를 의미함. normalize랑 아예 관계 없음!!
> 

```python
from sklearn.metrics.pairwise import euclidean_distances, manhattan_distances, cosine_similarity
import numpy as np

# 샘플 데이터 (2개의 벡터)
A = np.array([[1, 2, 3]])
B = np.array([[4, 6, 3]])

print(euclidean_distances(A, B))
# [[5.0]]  → √((4-1)²+(6-2)²+(3-3)²) = √(9+16+0) = 5
print(manhattan_distances(A, B))
# [[7.0]]  → |4-1|+|6-2|+|3-3| = 3+4+0 = 7
print(cosine_similarity(A, B))
# [[0.945...]]  → 1에 가까울수록 방향이 비슷함
```

## 지도학습

- 선형 회귀 분석 (Linear Regression)
    - 다중선형회귀 / 단순선형회귀 - 독립변수 많을 때
    - 회귀모델의 추정 - OLS (Ordinary Least Squares)
    - 평가지표 - R² (결정계수)
    - 다중 공선성
        - 독립변수 간 강한 상관관계가 나타나는 것
        - 변수들이 서로 엮여있으면 이 효과가 A 때문인지 B 때문인지 구분을 못함
        - VIF (분산 팽창 계수)
            - VIF는 최소값이 1이고 최대값은 무한대
            - 임계치를 넘어가면 하나씩 제거해볼 것
- 로지스틱 회귀 분석 (Logistic Regression)
    - 종속변수가 범주형일 때 사용
    - 왜 이름이 회귀?
        - 내부적으로 선형 회귀처럼 **선형 결합을 계산**한 다음, 그 값을 **시그모이드 함수**로 0~1 사이 확률로 변환
        - 종속 변수의 예측값은 0~1 사이의 확률로 나오며 이를 이진 값으로 변환함
- k-최근접 이웃 (k-NN)
    - 특정 데이터를 k개의 인접한 데이터 포인트를 기반으로 예측
        1. 새로운 데이터 ★ 입력
        2. 기존 데이터 전체와 거리 계산
        3. 가장 가까운 k개 선택
        4. k개 중 가장 많은 클래스로 분류
    - k값
        - k 가 작을수록 노이즈에 민감 —> 과대적합 위험
        - k 는 보통 홀수로 선택함 (짝수면 무승부 나올 수 있음)
    - 종속 변수에 따라 분류 모델과 회귀 모델로 나뉨
        - 분류: k개 중 다수결 (강아지 / 고양이)
        - 회귀: k개의 평균값 (집값 예측)
    - 특징
        - 학습 과정이 없음 (새 데이터 추가가 쉬움)
        - 평가 데이터세트가 인입되기 전에 train data set를 사용한 모델 학습이 없음
        - 피처 스케일에 민감 → **반드시 정규화 필요**
        - 예측할 때마다 전체 데이터와 거리 계산 → **느림**
- 의사결정나무 (Decision Tree)
    - 의사결정 규칙을 도표화하여 종속 변수를 예측
    - 어떤 기준으로 쪼개나?
        - 불순도를 많이 줄이는 기준!
            - 불순도란 한 노드 안에 여러 클래스가 섞여있는 정도
    - 불순도 측정
        - 지니 불순도 $Gini = 1 - \sum p_i^2$
        - 엔트로피 $Entropy = -\sum p_i \log_2(p_i)$
            - 지니보다 계산이 좀 더 복잡
            - 둘다 작을수록 더 좋음 (단일 범주라는 뜻)
    - 분할 기준 선택
        - 정보 이득 (Information Gain)
            - 현재 노드의 불순도 - 분할 후 자식 노드들의 불순도 평균
        - 정보 이득이 가장 큰 기준으로 분할한다
    - 과적합 방지
        - 트리를 계속 키우면 훈련데이터 과적합됨 → Pruning
    - 단독으로는 잘 안쓰고 앙상블로 쓰는 게 일반적
- 나이브 베이즈 분류기
    - **베이즈 정리**를 이용해서 각 클래스일 확률을 계산하고, 가장 높은 클래스로 분류
    - $P(클래스|데이터) = \frac{P(데이터|클래스) \cdot P(클래스)}{P(데이터)}$
        - **P(클래스)**: 사전 확률 (스팸 메일이 전체의 30%)
        - **P(데이터|클래스)**: 해당 클래스에서 이 데이터가 나올 확률
        - **P(클래스|데이터)**: 이 데이터가 해당 클래스일 확률 (우리가 원하는 것)
- 앙상블 (Random Forest)
    - 2개 이상의 모델을 활용하여 단일 모델 대비 더 나은 성능의 모델을 만드는 것
    - 투표 - 서로 다른 모델의 예측치를 취합하여 결정 (다수결 / 확률평균)
    - 배깅 - 부트스트랩으로 여러 샘플을 생성해서 같은 모델을 여러 번 학습
    - 랜덤 포레스트
        - 배깅 + 의사결정트리의 조합
        - 의사결정나무 여러 개를 **각자 다른 데이터 + 다른 피처**로 학습시켜서 합치는 것
        
        ```python
        원본 데이터
            ↓ 부트스트랩 샘플링
        트리1 (일부 피처만 사용)
        트리2 (일부 피처만 사용)  → 다수결 → 최종 예측
        트리3 (일부 피처만 사용)
        ```
        
        - 피쳐 중요도 (변수 중요도)
            - 랜덤 포레스트는 학습 데이터의 피처 (변수)도 랜덤하게 선택
            - 각 피처가 얼마나 불순도를 줄였는지에 따라 중요도가 높아짐
        - MDI
            - 각 피처가 트리의 불순도를 얼마나 줄였는지
            - `rf.feature_importances_`
            - MDI는 카디널리티에 따라 편향될 수 있음
                - 카디널리티는 각 피처 별로 고유값의 갯수
                - 카디널리티가 높은 피쳐일수록 MDI가 높음
                    - 값이 많을 수록 분할 기회가 많아서 불순도를 줄일 기회가 많아서
        - Permutation Importance
            - 모델을 학습한 후 특정 피처를 랜덤하게 섞었을 때 성능이 얼마나 떨어지는가
            - 성능이 많이 떨어질수록 중요한 피처
        - Drop Column Importance
            - 특정 피처를 **아예 제거하고 다시 학습**했을 때 성능이 얼마나 떨어지는지는가
            - 매번 학습을 다시해야해서 성능이 엄청 느림

## 비지도학습

- k-means 군집분석
    - 데이터를 **k개의 그룹**으로 나누되, 같은 그룹끼리는 가깝고 다른 그룹끼리는 멀게
    - 비지도 학습이라 정답 레이블 없이 스스로 그룹을 찾음
    - 동작 과정
        1. centroid(중심점) k개를 랜덤하게 초기화
        2. 각 데이터를 가장 가까운 centroid에 할당
        3. 각 그룹의 평균으로 centroid 업데이트
        4. centroid가 변하지 않을 때까지 2~3 반복
    - 특징
        - 평균을 기준으로 계산하므로 이상치에 민감
    - 평가
        - 실루엣 분석
            - a(i) : 같은 군집 내 다른 점들과의 평균 거리 (응집도)
            - b(i) : 가장 가까운 군집과의 평균 거리 (분리도)
            - b(i) - a(i) / max(b, a) : 클수록 (1에 가까울수록) 잘 분류된 것
        - Dunn Index
            - 군집 간 거리의 최소값 / 군집 내 요소 간 거리의 최대값
            - 클수록 좋은 분류
